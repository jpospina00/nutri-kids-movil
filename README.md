# 🍎 NutriKids – Nutrición Infantil Inteligente

## 📌 Descripción  
**NutriKids** es una aplicación móvil que combina **nutrición infantil con inteligencia artificial** para generar menús personalizados, saludables y atractivos para niños. La app ayuda a padres y cuidadores a planificar comidas balanceadas, considerando preferencias, alergias y necesidades nutricionales específicas, fomentando hábitos alimenticios sanos desde la infancia.

---

## 🎯 Objetivo  
Desarrollar una plataforma intuitiva y segura que:  
✅ Genere planes alimenticios personalizados mediante IA  
✅ Gestione perfiles nutricionales infantiles  
✅ Ofrezca seguimiento y historial de consumo  
✅ Facilite la planificación semanal de menús  
  

---

## 🛠️ Stack Tecnológico  

### **Backend**  
- **Node.js** con Express  
- **PostgreSQL** – Base de datos relacional    
-  **APIs de IA** – Motor de recomendaciones  
- **Docker** – Contenerización y despliegue  


### **Frontend Móvil**  
- **Flutter** – Desarrollo multiplataforma (Android/iOS)  
- **Provider / Bloc** – Gestión de estado  
- **Mockups en Figma** – Diseño UI/UX  

### **Infraestructura**  

- **Git** – Control de versiones

## 📋 Definition of Ready (DoR)

 ✅ **Formato correcto** – Escrita con el formato *"Quién + Qué + Para qué"*
 ✅ **Criterios de aceptación claros** – Verificables y medibles  
 ✅ **Priorización definida** – Ubicada correctamente en el backlog según valor y urgencia    
 ✅ **Dependencias identificadas** – APIs listas, HU anteriores completadas, recursos disponibles              
 ✅ **Diseños listos** – Mockups o wireframes definidos (si aplican)  
 ✅ **Alcance comprendido** – El equipo entendió la HU durante la sesión de grooming
